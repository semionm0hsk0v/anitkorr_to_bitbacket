## Tool

`antikorr_invoke` — вызов навыка правовой экспертизы проекта НПА.

Параметры (в обёртке `data`):

- `thread_id` — обязательный UUID текущего чата, он же `chat_id` загрузки DOCX.
- `history_messages` — необязательно, по умолчанию []; используется только для выбора файлов.
- `file_ids` — необязательный список UUID файлов текущего сообщения: проект и пояснения.
  Непустой список имеет приоритет; иначе берутся файлы последнего сообщения пользователя
  с вложениями. Списки разных сообщений не объединяются, дубликаты удаляются.
- `message_id` — необязательный UUID ответа; иначе создаётся один UUID для всех пакетов.

Единственный вход — MCP `/mcp/`; SSE и `/upload` временной UI удалены.
Поддерживаются .docx, .pdf и .txt с текстовым слоем; OCR сканов не выполняется.
Скачивается только anonymized endpoint. Проект обязателен, пояснение его не заменяет.
S3 202 ожидается ограниченно, затем нужно повторить запрос позднее;
404 — загрузить файл заново; 422 — ошибка извлечения/обезличивания (не обязательно скан);
сетевой сбой/5xx — повторить позднее. Пустой текст, неверный UUID, формат и превышение
размера дают понятный ответ со статусом error, не вывод об отсутствии нарушений.

## Результат и прогресс

Скелет Message → короткие think-статусы → единственный последний `{"data": Message}`.
Response содержит текст и file_id DOCX после подтверждённой загрузки в S3
(kind=anonymized, chat_id=thread_id). Текст и DOCX получены из одного прогона.
Tool возвращает answer, thread_id, message_id, finish_reason (success/error).
Если DOCX не доставлен, текст сохраняется со статусом success и явным предупреждением,
file_id равен null. Base64 и внутренние исключения не выдаются.

## Ограничения результата

Если модель не завершила разбор шапки проекта, компетенция получает статус «не проверена»
с краткой причиной. Это не вывод об отсутствии полномочий; остальные направления продолжают проверку.

## Порядок

1. Убедись, что есть файл проекта НПА с текстовым слоем: приложенный файл (`file_ids`)
   или файл из истории того же проекта (`history_messages`). Пояснительная записка —
   опциональное дополнение, не замена проекта.
2. Вызови `antikorr_invoke`.
3. Не переписывай ответ tool своими словами — заключение уже уходит стримом.
